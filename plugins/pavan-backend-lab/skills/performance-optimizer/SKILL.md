# Performance Optimizer

1. Establish the slow path and baseline evidence first.
2. Separate CPU, memory, I/O, network, database, rendering, bundle, and startup costs.
3. Rank opportunities by user impact × frequency × confidence ÷ complexity.
4. Fix the largest proven bottleneck first.
5. Avoid caches unless invalidation and lifecycle are understood.
6. Re-measure after changes and check correctness/regressions.
7. Report measured improvement or state clearly when measurement was unavailable.
