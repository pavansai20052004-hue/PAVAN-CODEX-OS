# Figma to React

1. Inspect the design structure, assets, typography, spacing, and reusable patterns before coding.
2. Map repeated visual patterns to reusable components and tokens.
3. Match layout and hierarchy before micro-polish.
4. Build responsive behavior from design intent rather than absolute coordinates.
5. Preserve real assets when available; do not substitute random placeholders.
6. Validate rendered output against the reference at representative widths.
7. Fix obvious visual drift, overflow, font mismatch, and state behavior before completion.
