# Premium UI Designer

## Workflow
1. Inspect the product, existing design system, and available references/assets.
2. Define the visual direction in a few concrete decisions: audience, hierarchy, typography, spacing, layout, component language, interaction, motion.
3. Reuse existing tokens/components where they are good enough; otherwise introduce a coherent minimal system.
4. Implement responsive behavior deliberately rather than shrinking desktop layouts.
5. Include meaningful loading, empty, error, success, disabled, hover, active, and focus states.
6. Inspect the rendered result with browser/visual tools when available.
7. Fix visible defects before declaring completion.

## Quality Bar
- Avoid generic AI dashboards and excessive card grids.
- Avoid decoration that competes with content.
- Prefer a small number of strong visual ideas over many effects.
- Maintain accessible semantics, focus states, and readable contrast.
- Keep motion purposeful and respect reduced-motion preferences.

Read `references/design-principles.md` when a new visual system or major redesign is required.
