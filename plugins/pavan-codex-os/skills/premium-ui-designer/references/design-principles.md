# Design Principles

## Hierarchy
Every screen needs an obvious primary action or reading path. Use scale, weight, spacing, contrast, and placement before adding decoration.

## Typography
Use a compact type scale with clear roles. Avoid tiny body text, excessive uppercase, and too many weights.

## Spacing
Use a repeatable spacing rhythm. Larger conceptual boundaries deserve larger gaps than related controls.

## Layout
Prefer composition suited to the product rather than defaulting to a centered card grid. Check narrow mobile widths, common laptop widths, and large desktop widths.

## Color
Use semantic color intentionally. Keep neutral surfaces calm. Reserve high-chroma color for emphasis, status, or brand moments.

## Motion
Animation should communicate causality, continuity, or emphasis. Avoid constant decorative motion.

## Visual QA
Check clipping, overflow, accidental scroll, alignment, line length, empty states, disabled controls, focus rings, modal sizing, sticky elements, and touch targets.
