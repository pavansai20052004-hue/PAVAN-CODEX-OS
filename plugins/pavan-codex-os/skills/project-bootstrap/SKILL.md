name: project-bootstrap
description: Start a new software project from a requirement or hackathon brief with a minimal production-oriented architecture, clear verification commands, and only the dependencies that are justified.
---

# Project Bootstrap

1. Convert the brief into a thin vertical slice and explicit non-goals.
2. Choose the simplest stack that satisfies the requirement unless the user specifies one.
3. Create a clean directory structure, environment example, README, and deterministic dev/build/test commands.
4. Add lint/type/test foundations appropriate to the stack.
5. Build one working end-to-end path before adding breadth.
6. Avoid speculative infrastructure and dependency bloat.
7. Leave the project in a runnable, documented state.
