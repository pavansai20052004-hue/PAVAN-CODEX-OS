# Accessibility Design

1. Inspect semantic structure and accessible names before adding ARIA.
2. Verify full keyboard operation and visible focus.
3. Check forms: labels, instructions, errors, required state, and focus recovery.
4. Check contrast, zoom/reflow, reduced motion, touch targets, and non-color cues.
5. Check dialogs, menus, tabs, tables, live status, and custom widgets for expected interaction semantics.
6. Prefer native elements and simpler interaction models when they solve the problem.
7. Validate with available automated tooling plus manual keyboard inspection; do not claim full compliance from an automated scan alone.
