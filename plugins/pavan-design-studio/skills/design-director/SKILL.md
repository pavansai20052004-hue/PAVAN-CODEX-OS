# Design Director

1. Inspect product purpose, audience, brand, current UI, references, and technical constraints.
2. For ambiguous greenfield work, explore up to three clearly different visual directions; do not produce cosmetic variations of the same layout.
3. Choose or recommend one direction and define: hierarchy, type scale, spacing rhythm, color roles, surface language, icon/illustration approach, interaction density, and motion character.
4. Define the page composition before individual components.
5. Specify mobile/tablet/desktop behavior as layout decisions, not shrink rules.
6. List anti-patterns to avoid for this specific direction.
7. Hand implementation a compact design contract rather than a long mood essay.

Read `references/visual-directions.md` only when exploring style options.
