# React Project Overlay

- Prefer existing component/state conventions before introducing new libraries.
- Keep server state, local UI state, and derived state conceptually separate.
- Avoid unnecessary effects; derive values during render when possible.
- Use stable keys and accessible native elements before custom div-based controls.
- For major UI changes, run the premium UI workflow and visually verify the result.
- Run the project's typecheck, tests, and production build after meaningful changes.
