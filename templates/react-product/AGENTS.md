# React Product Template

## Structure
Prefer feature-oriented modules with reusable primitives:

```text
src/
  app/
  components/
  features/
  hooks/
  lib/
  styles/
  types/
```

## Baseline
- TypeScript
- accessible semantic HTML
- responsive layout from the beginning
- design tokens for typography/spacing/color
- error/loading/empty states
- lint + typecheck + tests + production build commands

Use the premium UI designer skill for the first major screen and production QA before release.
